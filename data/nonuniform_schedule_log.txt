[1] ★ 상단 집중 가설 검정

   L  m │ 상반부 비중 │ 균일 주기라면
   8  2 │   100.0 %   │    50.0 %
   8  4 │   100.0 %   │    50.0 %
   8  8 │    50.0 %   │    50.0 %
  12  3 │   100.0 %   │    66.7 %
  12  6 │   100.0 %   │    50.0 %
  12 12 │    50.0 %   │    50.0 %
  16  4 │   100.0 %   │    50.0 %
  16  8 │   100.0 %   │    50.0 %
  16 16 │    50.0 %   │    50.0 %

  균일 주기는 정의상 상반부 비중이 50 %% 다. 최적 위치가 그보다 높으면
  '위로 갈수록 촘촘해야 한다' 는 구조적 예측이 확인된다.

[2] ★ 균일 주기 제약의 실제 기회비용 (DPPM 기준)
  같은 검사 예산에서 최적 위치가 균일 주기보다 DPPM 을 얼마나 낮추는가:
   L= 8 m= 2  균일   8034.6 → 최적   2540.8  (68.38 % 개선)
   L= 8 m= 4  균일   3887.0 → 최적   1910.0  (50.86 % 개선)
   L= 8 m= 8  균일   1908.9 → 최적   1908.9  (0.00 % 개선)
   L=12 m= 3  균일   8059.7 → 최적   1961.0  (75.67 % 개선)
   L=12 m= 6  균일   3887.1 → 최적   1908.9  (50.89 % 개선)
   L=12 m=12  균일   1908.9 → 최적   1908.9  (0.00 % 개선)
   L=16 m= 4  균일   8061.1 → 최적   1912.7  (76.27 % 개선)
   L=16 m= 8  균일   3887.1 → 최적   1908.9  (50.89 % 개선)
   L=16 m=16  균일   1908.9 → 최적   1908.9  (0.00 % 개선)

  최대 개선: L=16, m=4 — 76.27 %

  종전 VII-H 는 '층수당 다중 주기 허용' 만 측정해 기회비용 0.000 %% 를 얻었고,
  이는 균일-주기 계열 안에서만 유효한 값이었다. 위치를 풀면 결과가 다르다.

[3] ★★ 최소 검사 예산 — 같은 품질을 몇 번의 검사로 달성하는가
  균일 k=1 은 L 회 검사해 하한에 도달한다. 최적 위치는 몇 회면 되는가?

  ★ 상단에 몰아서 검사하면 균일 매층 검사와 같은 출하 품질을 절반 이하의
    검사 횟수로 달성한다. 테스터가 병목인 본 모델에서 이는 곧 캐파 확보다.
    하한의 원인이 상단 층의 검사 기회 부족(dppm_floor.py)이므로, 그 기회를
