## 3. Phase 1 — Block Y 구현 (즉시 착수 가능)

**Block T 와 무관하게 착수할 수 있다.** x와 β만 있으면 돌아간다.

| 산출 | 내용 |
|---|---|
| `block_y.py` | E[layer], E[test], p_good, p_escape, p_complete, e_die, dppm 계산 |
| `data/block_y_output.csv` | (L,k) 9조합 표 |
| 검증 통과 | Interface 9절 1~6번 |

**구현 순서**
1. β=1 단순 케이스 먼저 (d(i) = ⌈i/k⌉×k) — 손계산과 대조 가능
2. β<1 확장 (기하분포 가중) — escape 경로 추가
3. 검증 6종 자동화 (assert 문으로)
4. x, β 스윕해서 단조성 육안 확인

**완료 판정**: k를 바꿔도 p_good이 변하지 않고, k↓일 때 e_layer↓·e_test↑가 성립한다.

## 4. Phase 2 — 결합층 + MILP

### 4.1 ★ 핵심 전략: placeholder로 먼저 돌린다

**Block T 계수를 기다리지 않는다.** 필요한 계수(t_stack, t_fix_a, H_b, H_t, ψ)는 전부 **스칼라 6~7개**다. 06_Parameters에서 확보한 범위의 중앙값을 placeholder로 넣고 MILP를 완성한다.

| 계수 | placeholder 근거 |
|---|---|
| t_stack | 5.4초 (3.6~7.2 중앙, SemiAnalysis) |
| t_fix_a | ψ=0.2 가정에서 역산 |
| H_b, H_t | 비율 파라미터로 두고 상대값만 |

**실측값이 확보되면 숫자만 갈아끼운다. 구조는 그대로다.**

이것이 Interface 병렬 구조의 실질적 이득이다. **한 모듈의 미확정이 다른 모듈로 전파되지 않는다.**

### 4.2 작업 목록

1. 분수형 목적함수 선형화 — Charnes-Cooper vs 캐파 등호 고정 중 택1
2. PuLP로 MILP 정식화 (변수 q_L 3개 + k_L 선택 이진변수 9개)
3. 결합 함수를 **공동 파일 한 곳**에 배치
4. Interface 9절 7~9번 검증 (극단값 C, 문헌 재현, 단위 정합)

**⚠️ 8번 검증(문헌 재현)이 관문이다.** 캐파 제약을 풀었을 때 선행연구 결론(층수 최적점 존재)이 나와야 한다. 여기서 막히면 Phase 3으로 못 넘어간다.

### 6.1.1 ★ 파라미터 몬테카를로는 유지한다 (2026.08.12 확정)

**Spec 5.1과 7절이 충돌하고 있었다.** 서로 다른 몬테카를로를 말하고 있었기 때문이다. 아래로 분할해 해소한다.

| 대상 | 판정 | 근거 |
|---|---|---|
| **불량 발생 사건**의 MC | **버린다** | 조기 폐기가 closed form. 중복 계산 |
| **파라미터 불확실성**의 MC | **유지한다** | 삼각분포 스윕, 코드 30줄. **정보가치 분석(6.2)의 전제** |

**closed form이라서 불필요한 게 아니라, closed form이라서 파라미터 MC가 싸다.** 결과가 "최적 층수 12단(90% CI: 8~12)" 형태가 되어 점추정보다 강하다. 템플릿은 Spec 5.1(Epoch AI, CC BY).

**⚠️ 단, 이것을 "시스템 시뮬레이션"이라고 부르지 않는다.** 삼성 JD의 시스템 시뮬레이션은 DES 계열을 뜻한다. 면접에서 파라미터 MC로 그 칸을 채우면 역효과다. 7절 참조.

### 6.2 정보가치 분석 — 목표 문장

> "base die 원가비와 검사 단가는 50% 틀려도 최적 층수 구성이 바뀌지 않는다(|상관| < 0.04). 반면 **층당 접합 수율 x가 0.955에서 0.980으로 움직이면 16단 비중이 0%에서 100%로 뒤집힌다.** 그리고 **어느 설비를 증설할지는 검사시간 배수 θ = t_test/t_stack이 캐파 비율 자체보다 두 배 넘게 크게 좌우한다.** 따라서 이 의사결정에서 가장 정확히 측정해야 할 값은 x와 t_test이며, 원가 항목은 추정으로 충분하다."
>
> — Phase 3 몬테카를로 2,000회로 실제 산출된 결과다 (07_Results 4절)

**"데이터가 없었다"를 "무엇을 측정해야 하는지 규명했다"로 전환하는 지점.** 미확보 파라미터가 약점이 아니라 결론의 일부가 된다.
