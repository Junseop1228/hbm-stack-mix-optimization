## 2. 층위 A — 구조적 결과 (파라미터 무의존)

### 2.1 출하 DPPM 하한의 일반 닫힌형

> **Q = (1−β_f)(1−x^k) · Σ_{s=1..⌊L/k⌋} r^s ,  r = (1−β)/x^k**
> **DPPM_floor = 10⁶ · Q/(1+Q)**

닫힌형 대 해석식 48 조합 대조 — **최대 상대오차 6.4e-16 (기계정밀도 일치).**

### 2.2 ★ 하한은 층수에 무의존이다

Q 는 L 을 항 수 n = ⌊L/k⌋ 로만 포함하고 r < 1 이므로 급수가 수렴한다.

| k | L=8 | L=12 | L=16 | L→∞ 극한 | 편차 |
|---|---|---|---|---|---|
| 1 | **1908.9** | **1908.9** | **1908.9** | 1908.9 | **0.000 %** |
| 2 | 3887.0 | 3887.1 | 3887.1 | 3887.1 | 0.001 % |
| 4 | 8034.6 | 8059.7 | 8060.0 | 8060.0 | 0.315 % |

(x=0.965, β=0.95, β_f=0)

**k=1 에서 8단·12단·16단이 완전히 동일하다.** 이것이 본 연구의 헤드라인 수치 중 **유일하게 파라미터 구조에서 직접 나오는 결과**다.

### 2.3 ★ 하한의 원인 — 상단 블록의 검사 기회 부족

12단 k=1, β=0.95, β_f=0 층별 분해:

| 층 i | 검사 기회 m | escape 기여 | 누적 |
|---|---|---|---|
| **12** | **1** | **1.1826e-3** | **94.82 %** |
| 11 | 2 | 6.127e-5 | 99.73 % |
| 10 | 3 | 3.175e-6 | 99.99 % |

**최상단 1개 층이 94.8% 를 차지한다.** 상단 k개 층은 검사 지점이 구조적으로 1회뿐이다.

> **정정.** 종전 서술 "한 번 놓친 불량은 이후 검사에서도 같은 확률로 놓친다"는 검출 실패가 상관된 모델의 설명이며, 본 모델의 독립 가정 `(1−β)^m` 과 어긋난다. 독립이면 기회가 늘수록 escape 는 지수적으로 감소하므로 그 설명은 하한을 설명하지 못한다.

**구조적 함의** — escape 는 상단에 집중되고 조기 폐기 이득은 하단에서 최대다. 따라서 **최적 검사 스케줄은 균일 주기가 아니라 위로 갈수록 촘촘해야 한다.** 비균일 위치 최적화는 이월.

## 3. 층위 B — 임계 조건 (곡면으로 보고)

### 3.1 ★ 임계 φ_f = 2.0285 — 층수 내부 최적점의 존재 조건

캐파를 단일 풀로 합쳤을 때(검증 8 설정) 선행연구 결론인 "층수 내부 최적점 존재"가 재현되는지는 φ_f 에 달렸다.

| φ_f | 최적 층수 | 내부 최적점 | 단봉성 |
|---|---|---|---|
| 0 ~ 2.00 | **12단** | YES | OK |
| **2.0285** | **← 임계값** | | |
| 3.0 이상 | 16단 | **NO (경계해)** | FAIL |

최종 검사 시간은 출하 스택당 층수와 무관하게 부과되므로 높은 층수가 이를 분산한다. **이 힘이 수율의 지수적 하락을 넘어서면 내부 최적점이 소멸한다.**

φ_f ≥ 임계값 구간에서 모델은 "후보 중 가장 높이 쌓아라"를 답하며, **참 최적점이 후보 집합 {8,12,16} 밖에 있을 수 있다**는 뜻이다.

### 3.2 병목 전환점은 두 미확보 파라미터에 지배된다

| φ_f | 전환 H_t/H_b | 기준 믹스 |
|---|---|---|
| 0 (M1 정정 전) | 1.1398 | 8단 73% + 12단 24% + 16단 3% |
| **1.0 (기준)** | **1.2872** | **12단 97% + 16단 3%** |
| 3.0 | 1.5820 | 16단 98% + 12단 2% |
| 5.0 | 1.7463 | 동일 |

| θ | 전환 H_t/H_b | 병목 |
|---|---|---|
| 1.0 | 0.5095 | **본더** |
| 2.0 | 1.0547 | 테스터 |
| 3.0 (기준) | 1.5820 | 테스터 |
| 5.0 이상 | — | **실행 불가** |

**단일 수치로 보고하는 것은 부적절하다.** θ 를 1 → 3 으로 움직이면 병목이 본더에서 테스터로 바뀐다.

### 3.3 품질 목표에 따른 전환점 — knee

| DPPM 상한 | 전환 H_t/H_b |

**425 ppm 을 경계로 두 체제로 갈린다.** 다만 격자 해상도가 ±25 ppm 이므로 knee 는 "400~425 ppm 구간"으로 읽어야 한다.

## 5. 전역 민감도 분석

> **명칭 정정.** 종전 "정보가치 분석"은 부적절하다. 아래는 **Pearson 선형 상관**이며, 정보가치(EVPI/EVPPI)는 불확실성 해소 시 목적함수의 기대 개선분으로 정의가 다르다. EVPPI 산출은 이월한다.

### 5.1 몬테카를로 (삼각분포 11개 파라미터, 2,000회)

**실행 가능 566회 (28.3%).** 실행 불가는 대부분 β·β_f·φ_f 조합이 200 ppm 을 달성하지 못하는 경우다.

| 항목 | 중앙값 | 90% 구간 |
|---|---|---|
| 8단 비중 | **0.0%** | 0 ~ 45.3% |
| 12단 비중 | 12.5% | 0 ~ 89.9% |
| 16단 비중 | **70.4%** | 4.1 ~ 100% |
| k=2 비중 | 48.3% | 0 ~ 95.9% |
| 시간당 이익 J | 0.1440 | 0.0708 ~ 0.2610 |
| **P(병목 = 테스터)** | **약 87%** | 가정한 ρ 범위 조건부 |

**⚠️ 절단표본 주의** — 실행 가능 566건만 사용했고, 실행 가능성은 β·β_f·φ_f 로 결정되며 그 값들이 결과와도 상관된다. **아래 상관은 절단표본 위의 값이다.**

### 5.2 상관계수 (Pearson, n = 566)

| 파라미터 | →16단 비중 | →시간당 이익 | →테스터 병목 |
|---|---|---|---|

| **θ (검사시간비)** | +0.240 | −0.319 | **+0.311** |
| **φ_f (최종검사비)** | +0.197 | −0.035 | **+0.160** |

| β_f | +0.023 | +0.054 | **−0.219** |
| a | +0.021 | −0.080 | −0.152 |

**해석 주의 2건 — 둘 다 기계적 귀결이며 발견이 아니다.**

**r 의 이익 상관 +0.739.** 매출 스케일 파라미터이므로 이익에 비례하는 것이 당연하다. 층수 구성 상관은 −0.007 로 0 이다.

### ★ 병목이 검사 전략을 뒤집는다

> **본더가 병목이면 검사를 최대로(k=1), 테스터가 병목이면 최소로(k=4) 한다.**

본더가 병목이면 테스터 시간이 상대적으로 여유이므로 자주 검사해 불량을 조기 폐기하고 본더 시간을 아끼는 것이 순이득이다. 테스터가 병목이면 검사 자체가 병목 자원을 소모한다. **M1 정정 후에도 이 방향은 유지됐다.**

**주의** — "믹스 종수 ≤ 동시 구속 제약 수"는 발견이 아니라 **LP 기저의 표준 성질**이며, 축퇴가 없을 때 등호가 성립한다.

## 7. 균일 주기 제약 — 기회비용 주장 철회

| 조건 | single_k=True | single_k=False | 이익 차 |
|---|---|---|---|
| **기준선** | 12단k2 97% + 16단k4 3% | **완전 동일** | **+0.000%** |
| C4 해제 | 12단k4 74% + 16단k2 26% | 12단k2 30% + 12단k4 70% | — |

**기준선에서 균일 주기 제약의 기회비용이 0이다.** 종전 "+0.11% / +1.43%, 1.5% 이내"는 φ_f = 0 조건의 값이었으므로 **해당 주장을 철회한다.**

**층수 다양화 ↔ 검사 주기 다양화 대체재 현상**은 C4 비구속 조건에서만 관측된다 — 12단이 두 주기를 가질 수 있으면 16단이 사라진다. 범위를 그렇게 좁힌다.

**그리고 이 측정은 균일-주기 계열 안에서만 유효하다.** 비균일 검사 **위치**는 시험하지 않았고, 2.3 에 따르면 그쪽이 진짜 개선 방향이다.

| 전환점 1.2872 | 동일. θ·φ_f 에 강하게 의존 (3.2) |
| MC 실행가능 28.3%, 16단 중앙값 70.4% | 11개 삼각분포 기준. **절단표본** |
| 검증 8 통과 | **φ_f < 2.03** (3.1) |
| 상단 블록 지배 94.8% | 파라미터 무의존 (구조적) |

**아직 할 수 없는 말** — "최적 층수는 12단이다." 90% 신뢰구간이 0~89.9% 다.

## 9. 한계

| 항목 | 상태 |

| 캐파·용량계획 문헌 서베이 | **미수행.** "캐파 문헌에 품질이 없다"는 주장을 조사 범위 내로 축소 |
