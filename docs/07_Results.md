## 2. Gate 0 — 층수 최적점의 존재 조건

기준 시나리오(r=5, F=6, θ=3, x=0.965, β=0.95)에서 **a\*(8→12) = 1.40, a\*(12→16) = 10.32.**

**8→12 임계가 현실 범위 안쪽이므로 차별점 ③이 성립한다.** t_stack=5.4초 환산 시 t_fix_a ≈ 7.6초로, 로딩·정렬 시간으로 전혀 무리가 없다. 반면 16단 임계는 범위 밖이라 **16단은 C2가 강제할 때만 등장한다** — Spec 8.3 해석 경로의 실제 발동.

**모델 오차의 크기 (외부 리뷰 대조)**

| 모델 | a\*(8→12) |
|---|---|
| E[layer] ≈ L 근사 + 원가항 제외 (외부 리뷰) | 5.3 |
| E[layer] 실제값 + 원가항 제외 | 2.4 |
| **정식 모델 (원가항 포함)** | **1.40** |

**E[layer]를 L로 근사하면 임계 a가 약 4배 과대평가된다.** k=1·β=1의 닫힌형은 E[layer] = (1 − x^L)/(1 − x)이며, L=16에서 12.44로 L보다 22% 작다. 조기 폐기가 높은 층수를 유리하게 만드는 힘이므로 근사하면 안 된다.

**민감도 순위**: x(지배적) > F > θ > β(미미). **β는 0.84~1.0 전 구간에서 임계 a가 1.32~1.61로만 움직인다** — 미확보 파라미터가 결론을 흔들지 않는다는 정량 근거이며, 6.2 정보가치 분석의 1차 재료다.

**부수 발견 — DPPM은 L이 아니라 k가 결정한다.** 9조합 전부에서 dppm이 k별로 동일하다 (k=1: 1,909 / k=2: 3,887 / k=4: 8,035~8,061 ppm). 층수가 바뀌어도 출하 품질은 거의 같다. **따라서 C4는 사실상 k에만 걸리는 제약이며, 층수 결정에는 개입하지 않는다.** 모델 구조가 깔끔하게 분리된다.

**★ 최대 발견 (2026.08.12 S-1에서 정정) — 믹스의 종수는 동시에 구속되는 제약의 개수를 넘지 못한다.**

당초 이 자리에 "제품 믹스를 만드는 것은 품질 제약(C4)이다"라고 적었으나 **귀속 오류였다.** 전체 해제 대 전체 적용을 비교하고 차이를 C4 하나에 몰아 준 것이다. 제약을 하나씩 끄고(leave-one-out) 하나씩만 켜서(only-one) 분해한 결과는 아래와 같다. 원본은 `data/constraint_attribution_log.txt`, 코드는 `src/check_constraint_attribution.py`.

**기준선 조건**: x=0.965, β=0.95, a=3, θ=3, H_t/H_b=0.90, **cap=5,000 ppm, β_f=0(최종 검사 미도입)**. C3(웨이퍼)는 캐파 해제 시 발산을 막는 통제 상수로 전 케이스 상시 적용.

**⚠️ 이 절의 수치는 위 설정에서 산출된 S-1 실험 기록이며, 그 실험의 결과로서 유효하다.** 현행 설정의 수치는 0.1 정본 표를 볼 것.

| 켜진 제약 | 층수 배분 (8/12/16) | 주기 배분 (k1/k2/k4) | 출하 DPPM | 종수 |
|---|---|---|---|---|
| C3(웨이퍼)만 | 0 / 100 / 0 | 100 / 0 / 0 | 1,909 | **1종** |
| C4 단독 | 0 / 100 / 0 | 100 / 0 / 0 | 1,909 | 1종 |
| C2 단독 | 0 / 100 / 0 | 100 / 0 / 0 | 1,909 | 1종 |
| C1a 단독 | 0 / 100 / 0 | 100 / 0 / 0 | 1,909 | 1종 |
| C1b 단독 | 3 / 97 / 0 | 0 / 3 / 97 | 7,937 | 2종 |
| **C1a + C1b** | **0 / 58 / 42** | **0 / 58 / 42** | 5,503 | **2종** |
| **C1a + C1b + C4 (기준선)** | **48 / 20 / 32** | **0 / 68 / 32** | 5,000 | **3종** |

**결론 1 — 종수는 구속 제약 개수를 넘지 못한다.** LP 기저 최적해의 비영 변수 개수는 구속 제약 개수 **이하**다. 등호가 아니라 부등호이며, 축퇴(degeneracy)가 있으면 더 적게 나온다 — 위 표에서 일치한 것은 축퇴가 없었기 때문이지 등식이 성립해서가 아니다. **캐파 제약이 하나뿐이면 원리적으로 단일 구성이 나오고, 둘이면 2종까지 가능해진다.** 어느 한 제약이 믹스를 "만드는" 것이 아니다.

**결론 2 — 믹스의 뼈대는 본더·테스터 두 캐파 제약의 동시 구속이다.** C1a+C1b만으로 12단k2 + 16단k4 2종이 나온다.

**⚠️ 단, 이것을 "믹스가 발생한다"는 성과로 보고하면 안 된다.** 구속 제약이 둘이면 기저 변수가 둘까지 나올 수 있는 것은 LP의 성질이며, **"제약을 둘 넣었으니 당연한 것 아니냐"**는 반론에 무너진다. **차별점 ②의 본질은 결과가 아니라 모델링 범위다** — "층수가 다른 이질적 제품을 하나의 설비 위에서 동시에 다룬다"가 본체이며, 선행 계보가 전부 단일 제품·단일 스택인 것은 LP 기저와 무관한 문제 설정의 차이다. 서술 교체는 01_Spec 6.1에 반영했다.

**결론 3 — C4가 제약하는 것은 검사 주기 k다.** C4를 끄면 k2 비중이 68%→58%로 풀리고 DPPM이 5,000→5,503으로 올라간다.

**⚠️ 층수 쪽 부작용의 메커니즘은 미규명으로 남긴다.** 당초 "층수마다 검사 주기를 하나만 고를 수 있으므로(`single_k`) 늘어난 k2 물량을 8단이 떠맡는다"고 해석했으나, **`single_k=False` 반증 테스트에서 기각됐다.** 해제해도 8단이 남고 오히려 늘어난다 (`src/check_single_k.py`, `data/single_k_log.txt`).

| 케이스 | 8단 | 12단 | 16단 | 총이익 |
|---|---|---|---|---|
| single_k=True, C4 on (기준선) | 48% | 20% | 32% | 1.4319e+07 |
| single_k=False, C4 on | **65%** | 35% | **0%** | 1.4335e+07 |
| single_k=True, C4 off | 0% | 58% | 42% | 1.4597e+07 |
| single_k=False, C4 off | 0% | **100%** | **0%** | 1.4806e+07 |

**확정 사실은 두 가지다.** 첫째, **8단은 C4를 켤 때만 등장하며 `single_k`와 무관하다.** 등장 원인은 규명하지 못했다. 둘째, **16단이야말로 `single_k`의 산물이다** — 해제하면 C4 유무와 무관하게 사라지고 12단이 두 주기를 나눠 갖는다.

**★ 16단이 사라지는 것이 대표 결과 ②를 위협하는지 확인했고, 위협하지 않는다.** x 스윕을 양쪽 설정으로 돌린 결과 x ≥ 0.980에서 두 설정 모두 16단 100%이고, `single_k=False`에서는 오히려 x=0.975부터 100%가 된다. **고수율 구간의 16단 지배는 층수 경제성이 원인이며 모델링 선택의 산물이 아니다.** 기준선 x=0.965가 전환 구간 한복판이라 설정에 민감할 뿐이다 (`data/single_k_xsweep_log.txt`). 단 **전환 구간의 층수 배분이 `single_k`에 민감하다는 사실은 한계로 명시한다**(01_Spec 8.2).

**교훈 — 이번에도 검증 없이 메커니즘을 단정할 뻔했다.** "믹스는 C4가 만든다"를 정정하면서 그 자리에 또 다른 미검증 해석을 채워 넣었다. **정정 작업 자체가 같은 종류의 오류를 재생산할 수 있다.**

**결론 4 — C2(수요 세그먼트)는 기준선에서 비구속이다.** 듀얼이 정확히 0이고, 꺼도 결과가 완전히 동일하다(위 표 −C2 케이스는 기준선과 일치). 현재 SEG가 달성 가능량의 40%/18%로 느슨하기 때문이며, **지금 C2는 장식이다.** S1.5에서 수요를 절대 상수로 재정의하면 이 판정을 다시 해야 한다.

**⚠️ "무제약"이라는 표현도 부정확했다.** 12단 k=4는 **시간 단일 풀 캐파 하의 해**이며(검증 8, 듀얼 0.20754), 캐파를 전부 풀고 웨이퍼만 남기면 12단 **k=1**이 최적이다. 시간당 이익 기준이냐 die당 이익 기준이냐에 따라 k가 갈린다. **앞으로 "무제약"은 무엇을 해제했는지 반드시 명시한다.**

**★ 이 오류는 Phase 1 결과와 대조했으면 잡혔다.** 9.0.1이 이미 **"DPPM은 L이 아니라 k가 결정한다"**를 확인해뒀으므로, 그 역방향인 **"C4는 L이 아니라 k를 제약한다"**가 자명하게 성립해야 했다. Phase 2 보고가 Phase 1 결과와 앞뒤가 안 맞는데도 두 Phase를 대조하지 않아 넘어갔다. **Phase 간 정합성 점검을 절차로 넣어야 한다.**

**병목 전환점**: H_t/H_b가 **0.8과 0.9 사이**에서 테스터 → 본더로 넘어간다. 대표 그림 1번의 x축 위치가 확정됐다.

## 4. Phase 3 — 시나리오와 파라미터 불확실성

`src/scenarios.py`. 수요는 전 시나리오에서 고정했다 — **캐파가 변해도 고객 수요는 변하지 않기 때문**이다.

### 대표 결과 3개

**① 병목 전환점 = H_t/H_b = 1.1398** (이분탐색, cap = 200 ppm 기준)

**⚠️ 이 값은 품질 목표에 따라 움직인다 (S3-6).** cap ≥ 425 ppm 에서는 0.5837 로 평탄하고, cap ≤ 400 ppm 부터 급증해 200 ppm 에서 1.1398 이 된다. 상세는 0.1 정본 표.

테스터 캐파가 본더의 86.6% 미만이면 테스터가, 초과하면 본더가 병목이다. **설비 증설 우선순위를 이 한 숫자가 결정한다.** 전환 직후 믹스가 8단k2 68% 단순 구성에서 8단/12단/16단 3종 혼합으로 갈라진다.

**② 층당 수율 x가 층수 구성을 지배한다** (차별점 ③)

| x | 최적 믹스 |
|---|---|
| 0.940 | 8단 48% + 12단 52%, **16단 0%** |
| 0.965 | 8단 48% + 12단 20% + 16단 32% |
| 0.980~ | **16단 100%** |

**층당 수율 1.5%p 차이가 16단 비중을 0%에서 100%로 뒤집는다.** 업계의 16단 도입 시점이 "수율에 좌우된다"는 진술(06_Parameters D6)과 정합한다.

**③ 고정시간 배수 a가 최적 층수를 밀어올린다** (차별점 ②)

a = 0~2에서 8단+16단, a = 3~6에서 12단 중심, a ≥ 8에서 16단 지배. Gate 0의 임계값과 방향이 일치하되, **캐파·수요·품질 제약이 붙으면 단일 구성이 아니라 혼합으로 나온다.**

### 부수 결과 3건

**시나리오 F — 매출 선형성 가정은 강건하다.** 06_Parameters 5.3이 제기한 반증 가능성을 시험했다. **16단 $/GB 프리미엄이 15%까지 올라도 최적 믹스가 전혀 바뀌지 않는다.** 25%에서야 뒤집힌다. → **한계가 아니라 강건성 근거로 보고한다.**

**시나리오 D — 검출률이 낮으면 어떤 검사 주기로도 품질을 못 맞춘다.** **β_f=0.95 · cap=200 ppm 기준에서 β ≤ 0.88 이면 실행 불가**다(`data/scenario_d_log.txt`). k 를 1 까지 낮춰도 200 ppm 을 넘는다.

**근거가 강화됐다.** 이제 β 스윕뿐 아니라 **β_f 역산 표**가 같은 결론을 준다 — **최종 검사가 없으면(β_f=0) 어떤 k 로도 1,000 ppm 아래로 갈 수 없다.** **검사 빈도로는 검사 정확도를 대체할 수 없다.**

**시나리오 θ — 검사시간이 층 적층시간의 8배를 넘으면 실행 불가.** 테스터가 수요를 감당하지 못한다.

### 몬테카를로 (삼각분포 · 2,000회)

| 항목 | 중앙값 | 90% 신뢰구간 |
|---|---|---|
| 8단 비중 | 29.9% | 0 ~ 81.5% |
| 12단 비중 | 21.0% | 0 ~ 100% |
| 16단 비중 | 17.1% | 0 ~ 100% |
| 시간당 이익 J | 0.1554 | 0.0761 ~ 0.2953 |
| **병목 = 테스터일 확률** | **66.9%** | — |

**실행 2,000회 중 실행가능 953회(47.6%)** — cap 200 ppm, β~Tri(0.84,0.95,0.99), β_f~Tri(0.87,0.95,0.99) 기준. 실패는 β 또는 β_f 가 낮아 200 ppm 을 못 맞추거나 θ 가 커서 테스터가 수요를 못 채우는 경우다.

**★ 이 비율은 감소가 아니라 결과다.** 종전 65.8%(cap 5,000)에서 떨어진 것으로 읽으면 안 된다.

> **품질 목표를 200 ppm 으로 잡으면 검사 정확도 조합의 절반 이상이 그 목표를 달성할 수 없다.**

**"이 공장으로는 불가능한 영역이 절반"이라는 것이 실무적으로 의미 있는 문장이다.**

**⚠️ 층수 비중의 신뢰구간이 0~100%로 매우 넓다.** 점추정으로 "최적은 12단"이라고 말할 수 없다는 뜻이며, **01_Spec 5절이 처음부터 점추정을 목표로 두지 않은 이유**가 수치로 확인됐다.

### 정보가치 분석 — 무엇을 측정해야 하는가

파라미터와 결과의 상관계수 (n=953, β_f 포함 10개) — **최신 값은 0.1 정본 표**

| 파라미터 | →16단 비중 | →시간당 이익 | →테스터 병목 |
|---|---|---|---|
| **x (층당 수율)** | **+0.537** | +0.376 | −0.102 |
| c_fix_b | +0.154 | −0.077 | +0.033 |
| a | +0.149 | −0.137 | −0.202 |
| **θ (검사시간 배수)** | −0.122 | −0.236 | **+0.450** |
| β | −0.107 | +0.105 | −0.328 |
| ρ (캐파 비율) | +0.059 | −0.108 | −0.212 |
| r (층당 매출) | −0.055 | +0.746 | −0.037 |
| c_test | −0.038 | −0.031 | +0.055 |
| c_base | +0.012 | −0.029 | +0.025 |

**r의 이익 상관(+0.746)은 정보가치가 없다.** 매출 스케일 파라미터라 이익에 직접 비례하는 게 당연하다. **의사결정을 바꾸지 않는 상관은 제외해야 한다** — r의 16단 비중 상관은 −0.055로 사실상 0이다.

**결론 문장 2개**

> **층수 구성**을 정하려면 **층당 접합 수율 x**를 가장 정확히 알아야 한다(+0.537). 원가 항목(c_base, c_test)은 50% 틀려도 결론이 안 바뀐다(|r| < 0.04).
>
> **어느 설비를 증설할지**를 정하려면 **검사시간 배수 θ = t_test / t_stack**을 가장 정확히 알아야 한다(+0.450). 캐파 비율 ρ 자체(−0.212)보다 두 배 넘게 중요하다.

**θ가 병목을 지배한다는 것이 이번 Phase의 최대 실무 시사점이다.** 06_Parameters 6절이 t_test를 미확보 1순위로 둔 것이 옳았음이 사후 확인됐고, **어떤 값을 먼저 실측해야 하는지가 숫자로 정당화됐다.**
