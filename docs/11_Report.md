## 초록

HBM(High Bandwidth Memory)은 DRAM 다이를 수직으로 적층해 제조하며, 층수가 증가할수록 용량은 선형으로 늘지만 복합 수율은 지수적으로 하락한다. 적층 도중의 주기적 검사는 불량 스택을 조기에 폐기해 이후 공정의 설비 시간을 절약하지만, 검사 자체가 테스터 설비 시간을 소모한다.

기존 3D 적층 원가 모델 계보는 **원가만을 목적으로 하며 설비 처리량 제약을 다루지 않는다.** 또한 층수를 주어진 파라미터로 두고 탐색공간이 다이 수에 대해 O(N^(l²))로 증가해 실험 규모가 최대 5-die에 머문다.

본 연구는 층 단위 주기 검사 패턴으로 탐색 구조를 제약해 12~16단 규모를 다룰 수 있게 하고, **본더·테스터의 처리량 제약과 층수 구성별 제품 믹스를 결정변수로 추가한** 혼합정수선형계획(MILP) 모델을 제시한다. 설비·원가 계수의 절대값이 공개되지 않으므로, 입력을 데이터셋이 아닌 **파라미터 공간**으로 두고 삼각분포 몬테카를로로 확률적 결론을 보고한다.

주요 결과는 다음과 같다. 첫째, **설비 증설 우선순위는 출하 품질 목표의 함수다** — 목표가 425 ppm보다 느슨하면 병목 전환점이 0.584로 고정되어 품질과 무관하나, 200 ppm에서는 1.140으로 상승해 테스터 캐파가 본더를 초과해야 한다. 둘째, **16단은 서로 다른 두 원인으로 등장한다** — 저수율 구간에서는 고객 용량 수요가 강제하고, 고수율 구간(x ≥ 0.9825)에서는 설비 경제성이 선택한다. 셋째, **최종 검사가 없으면 어떤 검사 빈도로도 1,000 ppm 아래에 도달할 수 없다**(하한 1,908.9 ppm). 넷째, **본더가 병목이면 검사를 최대로, 테스터가 병목이면 최소로** 하는 것이 최적이다. 다섯째, 정보가치 분석 결과 층수 구성은 층당 접합 수율(상관 +0.476)이, 병목 위치는 검사시간 배수(+0.417)가 지배하며 원가 항목은 0.06 미만으로 무관하다.

## 1. 서론

3D 적층은 배선 길이 단축과 대역폭 향상을 제공하며, HBM은 이 기술이 양산에 정착한 대표 사례다. 그러나 적층 공정에서 **다이 하나가 불량이면 스택 전체가 불량**이 되므로, 층수 증가는 수율 측면에서 지수적 불이익을 수반한다.

층당 접합 수율을 x, 층수를 L이라 하면 복합 수율은 x^L이다. x = 0.965에서 8단은 75.2%, 12단은 65.2%, 16단은 56.5%다. 반면 매출은 층수에 선형으로만 증가한다. **곱셈으로 나빠지고 덧셈으로 좋아지는 구조**이므로 무조건 높이 쌓는 것은 답이 아니다.

동시에 반대 방향의 힘이 존재한다. 캐리어 로딩·정렬 같은 적층 전 고정 작업은 층수와 무관하게 1회 발생하므로 높이 쌓을수록 층당 분산된다. 스택 하단의 base die 역시 층수와 무관하게 1장이 필요하다. 그리고 GPU당 HBM 스택 수가 정해져 있으므로 총 용량 목표가 최소 층수를 강제한다.

여기에 검사 결정이 얹힌다. 적층 도중 검사를 넣으면 불량 스택을 조기에 폐기해 이후 층의 적층·검사 시간을 절약할 수 있으나, 검사 자체가 테스터 설비를 점유한다. 따라서 문제는 다음과 같이 요약된다.

> **제한된 설비 처리량을 더 높이 쌓는 데 배분할 것인가, 더 자주 검사하는 데 배분할 것인가.**

### 1.1 기여

본 리포트의 주요 기여는 다음과 같다.

- **설비 처리량 캐파 제약의 도입.** 선행 계보가 원가만을 다루는 것과 달리, 본더·테스터를 분리된 두 자원으로 모델링해 병목 판정과 설비 1초의 한계이익을 내생적으로 산출한다.
- **층수 구성별 제품 믹스.** 층수가 다른 이질적 제품이 하나의 설비를 공유하는 상황을 다룬다. 선행 계보는 전부 단일 제품·단일 스택을 전제한다.
- **층수의 결정변수화.** 선행연구가 주어진 파라미터로 두는 층수 l을 결정변수로 승격한다.
- **대규모 스택의 계산 가능성.** 층 단위 주기 패턴 k ∈ {1, 2, 4}로 탐색 구조를 제약해, O(N^(l²)) 폭발을 회피하고 12~16단을 다룬다.
- **파라미터 공간 기반 결론.** 절대값이 비공개인 계수를 삼각분포로 두고, 점추정이 아닌 **임계 조건과 신뢰구간**을 보고한다. 아울러 어떤 파라미터를 정확히 측정해야 하는지를 정보가치 분석으로 규명한다.

### 1.2 문서 구성

2절은 동기와 선행연구를 다루고 본 연구의 대비 위치를 밝힌다. 3절은 모델을, 4절은 최적화 문제의 정식화를 제시한다. 5절은 해법과 폐기된 대안들을 논한다. 6절은 검증 절차를, 7절은 결과를 보고한다. 8절은 논의와 한계를, 9절은 결론을 제시한다. 부록 A는 조기 폐기 기대값의 유도를, 부록 B는 재현 절차를 담는다.

## 2. 동기와 선행연구

### 2.1 문헌 지형도

3D 적층의 원가 모델과 테스트 흐름 최적화는 확립된 계보를 가진다. 조사 결과는 다음과 같다.

| 영역 | 상태 | 대표 문헌 |
|---|---|---|
| 3D 적층 원가 모델 | 선점 | 3D-COSTAR (Taouil 외, 3D-Test 2012), CATCH (Graening 외, IEEE TCAD 2025) |
| 테스트 흐름 선택 최적화 | 선점 | Agrawal & Chakrabarty (VTS 2013 / TCAD 2015) |
| Mid-bond test 원가 영향 | 선점 | Taouil 외 (DFT 2013) |
| 층수 최적점 존재 | 선점 | IEEE Xplore 4114978 (2006), Coskun 외 (DSD 2009) |
| 품질-원가 trade-off, DPPM | 선점 | Taouil 외 (VTS 2014) |
| D2W 원가 프레임워크 | 선점 | Taouil 외 (JETTA 28(1), 2012) |
| **설비 처리량 캐파 제약** | **공백** | 예산 제약 언급 1건 (2.3절) |
| **층수 구성별 제품 믹스** | **공백** | — |
| **층수를 결정변수로** | **공백** | — |
| **12~16단 계산 가능성** | **공백** | 실험 최대 5-die |

### 2.2 선행 계보의 목적함수

Agrawal & Chakrabarty는 총원가 대비 **양품 패키지당 원가**가 우월함을 실험으로 논증했다. 2-die 예제에서 총원가를 목적함수로 쓰면 양품 스택당 이익률이 2% 상쇄되며, 규모가 커지면 그 손실이 유의하게 확대된다고 보고한다.

본 연구는 이 판단을 수용하되, **캐파 제약이 존재하는 상황에서는 두 목적함수가 등가가 된다**는 조건을 명시한다. 상세는 4.2절에서 다룬다.

### 2.3 자원 제약에 대한 유일한 언급

선행 계보에서 자원 제약을 언급한 유일한 대목은 Agrawal & Chakrabarty의 결과 절이다. 제조·테스트 자원 공급이 제한된 경우 총 지출액에 대한 추가 제약 하에서 최적 흐름을 보고하도록 방법을 조정할 수 있으며, A* 탐색에서 g(n) + h(n)이 가용 자원을 초과하는 노드를 버리면 된다고 서술한다.

**이는 금액 기준의 예산 제약이며 시간 기준의 처리량 제약이 아니다.** 또한 조정 가능성을 언급했을 뿐 구현하지 않았다.

이 논문에는 시간 개념 자체가 부재하다. 테스트 비용을 전부 금액으로 다루며, 테스트 비용의 대리 지표로 **테스트 패턴 수**를 사용한다고 명시한다. 따라서 테스트 시간 → 설비 점유 → 캐파로 이어지는 연결이 성립하지 않는다.

### 2.4 선행연구가 남긴 확장 지점

같은 절 말미에서 저자들은 제조 흐름의 차이가 제조원가와 다이 수율을 바꾸고 이것이 최적 테스트 흐름에 영향을 준다고 지적하며, 제조 흐름과 테스트 흐름을 함께 평가하려면 **테스트 흐름 선택 도구를 반복 호출해야 한다**고 기술한다.

**본 연구는 이 반복 호출을 하나의 최적화 문제로 통합한다.** 제조 흐름에 해당하는 층수 선택과 테스트 흐름에 해당하는 검사 주기를 동일한 목적함수 안에서 동시에 결정한다.

### 2.5 대비 위치

따라서 본 연구의 위치는 "선행연구가 없다"가 아니라 **"선행연구가 후속 과제로 남긴 것을 생산관리 관점에서 다룬다"**이다. imec·TU Delft 계보는 모든 적층 제품에 통용되는 만능 테스트 흐름이 없다고 결론했고, Duke 계보는 원가 최소화의 일반 규칙을 명시할 수 없다고 밝혔다. 두 계보 모두 조건별 최적해를 미해결로 남겼다.

### 3.2 가정

**가정 1.** 층별 접합 실패는 서로 독립이며 동일한 확률 (1 − x)를 가진다. 따라서 L층 스택의 무결점 확률은 x^L이다.

**가정 2.** 검사의 효과는 **조기 폐기 하나로 한정한다.** 불량이 검출되면 해당 스택은 즉시 폐기되며, 이후 층의 적층 시간·검사 시간·die 소모가 발생하지 않는다. 수리(repair)와 층 여분(redundancy)은 범위 밖이다.

> **근거.** 수리 경로를 포함하면 어떤 불량이 수리 가능한지에 대한 공정 데이터가 필요한데 공개 자료가 없다. 조기 폐기만으로도 검사의 경제적 가치가 정의되며, 이것이 설비 시간과 직접 연결된다.

**가정 3.** 중간 검사는 층 단위 주기 패턴으로만 수행한다. 즉 k층마다 1회이며, 층수마다 하나의 k를 선택한다.

> **근거.** 현장은 조립업체의 공정에 따라 1층·2층·4층마다 검사하는 규칙적 패턴을 사용한다. 임의의 검사 위치 조합은 라인 운영이 불가능하며, 같은 층수 제품에 두 가지 주기를 동시에 운영하는 것도 같은 이유로 배제된다. 이 제약의 기회비용은 7.6절에서 정량화한다.

**가정 4.** 몰딩 이후 **최종 검사가 1회 존재하며 항상 수행된다.** 검출률은 β_f다.

> **근거.** HBM 표준 테스트 흐름은 초기 웨이퍼 레벨 테스트, 적층 후 **선택적** 중간 검사, 패키지 조립 후 **최종 테스트**의 3단계로 구성된다. 중간 검사가 선택적이므로 k가 결정변수이고, 최종 검사가 상시이므로 β_f는 파라미터다.

**가정 5.** 미검출 불량(escape)은 출하되어 DPPM에 계상되나, 반품·교체 처리되어 매출로 계상되지 않는다. 품질 원가(COPQ)의 표준 처리와 일치한다.

**가정 6.** 생산량은 전량 판매된다. HBM은 공급 부족 국면이며, 이 전제가 4.2절의 목적함수 선택을 정당화한다.

**가정 7.** mass reflow와 몰딩은 저가·고처리량 배치 설비이므로 캐파 병목이 아니다. 해당 시간은 캐파 제약에서 제외하고 원가에만 계상한다.

### 3.3 Block Y — 수율·검사

투입 스택 1개 기준으로 다음을 산출한다. 유도는 부록 A에 있다.

| 기호 | 의미 |
|---|---|
| p_good(L) | 무결점 스택 비율 = x^L |
| p_escape(L, k) | 불량이나 미검출로 출하된 비율 |
| p_ship(L, k) | 출하량 = p_good + p_escape |
| E[layer](L, k) | 폐기 전까지 실제 적층된 층수의 기대값 |
| E[test](L, k) | 수행된 검사 횟수의 기대값 |
| DPPM(L, k) | p_escape / p_ship × 10⁶ |

**핵심 성질.** p_good은 k에 의존하지 않는다. 검사 주기를 바꾸어도 최종 양품 수는 동일하며, 달라지는 것은 **불량 스택에 낭비한 설비 시간과 die**뿐이다. 이것이 조기 폐기 메커니즘이 설비 시간을 통해서만 작동하는 이유다.

k = 1, β = 1의 특수 경우에 E[layer]는 닫힌형을 가진다.

> E[layer] = (1 − x^L) / (1 − x)

x = 0.965에서 L = 16일 때 E[layer] = 12.42로, L보다 22% 작다. **이 값을 L로 근사하면 층수 전환 임계값이 약 4배 과대평가된다.**

### 3.4 Block T — 설비·원가

투입 스택 1개 기준 설비 점유시간과 원가는 다음과 같다.

> τ_bond(L, k) = t_fix_a + t_stack · E[layer]
> τ_test(L, k) = t_test · E[test]
> E[C](L, k) = c_base + c_die · E[layer] + c_test · E[test] + p_ship · c_fix_b
> R(L) = r · L · p_good

가정 7에 따라 적층 후 고정시간 t_fix_b는 캐파식에서 제외되고 원가식에만 남는다. **이것이 고정성분 분산 효과를 없애지 않는다** — 분모(설비시간)에서 분자(원가)로 이동시킬 뿐이며, 층수 무관 고정원가가 클수록 높은 층수가 유리해지는 방향은 유지된다.

### 3.5 모듈 분리

두 모듈은 서로 데이터를 주고받지 않는다. 각각 공통 입력 (L, k)를 받아 독립적으로 계산하고 결과를 결합층에 올린다. 결합 함수는 어느 모듈에도 속하지 않으며 단일 파일에 둔다.

> 한 모듈의 미확정이 다른 모듈로 전파되지 않는다. 실제로 Block T의 계수가 전부 미확보인 상태에서 Block Y와 결합층·시나리오 분석을 완주했다.

## 4. 문제 정식화

### 4.1 목적함수

> **maximize Σ_(L,k) [ R(L) − E[C](L, k) ] · q(L, k)**

**총이익 최대화**이며, 가정 6(전량 판매)이 전제다.

### 4.2 분수형 목적함수를 채택하지 않는 이유

초안은 레퍼런스 문헌의 "양품 패키지당 원가"에 대응하는 **설비시간 단위당 이익**을 목적함수로 두고 Charnes-Cooper 변환으로 선형화했다. 구현 후 실행한 결과 **모든 캐파 제약의 shadow price가 0**으로 산출됐다.

원인은 코드가 아니라 정식화였다.

> 분수형 목적함수는 규모에 무관하다(scale-invariant). "시간당 이익을 최대화하라"는 지시에 대한 모델의 최적 대응은 **덜 만드는 것**이다. 캐파를 소진할 유인이 없으므로 C1-a·C1-b가 구속되지 않고, **병목 판정이 정의되지 않는다.**

총이익 최대화로 정정하면 이 문제가 해소될 뿐 아니라 다음이 성립한다.

> **캐파 제약이 구속될 때, 그 shadow price가 곧 해당 설비 1초의 한계이익이다.**

즉 단위당 지표를 목적함수로 강제할 필요가 없다. **캐파 제약의 듀얼로 내생적으로 산출**되며, 병목은 두 듀얼 중 큰 쪽으로 정의된다. 이 등식은 6.2절 검증 8에서 수치로 확인했다.

레퍼런스 문헌이 양품 패키지당 원가를 권한 것은 **캐파 제약이 없고 생산량이 주어진 설정**에서다. 캐파가 하드 제약이고 물량이 내생이면 총이익 최대화가 곧 시간당 이익 최대화이며, 그 값이 듀얼로 나온다. **본 연구는 두 목적함수가 등가가 되는 조건을 명시한 것이다.**

### 4.3 제약

| 번호 | 내용 | 수식 |
|---|---|---|
| C1-a | 본더 처리량 | Σ τ_bond · q ≤ H_b |
| C1-b | 테스터 처리량 | Σ τ_test · q ≤ H_t |
| C2 | 고객 용량 수요 | Σ_{L ≥ L_s} c·L·p_good·q ≥ D_s |
| C3 | 웨이퍼 공급 | Σ (1 + E[layer]) · q ≤ W |
| C4 | 출하 품질 | Σ (p_escape − Q·p_ship) · q ≤ 0 |
| — | 층수당 단일 주기 | Σ_k y(L,k) ≤ 1, q(L,k) ≤ M·y(L,k) |

**C1을 두 제약으로 분리하는 것이 병목 판정의 전제다.** 단일 풀로 합치면 어느 설비가 먼저 소진되는지를 물을 수 없다.

C4는 분수형 제약이나 양변에 분모를 곱해 선형으로 변환된다.

## 5. 해법

### 5.1 MILP

결정변수는 (L, k) 조합 9개에 대한 연속변수 q와 이진변수 y다. 이진변수의 big-M은 각 조합의 캐파·웨이퍼 상한에서 자연적으로 확정되므로 임의 상수를 도입하지 않는다.

PuLP에 동봉된 CBC 솔버를 사용하며, 1회 풀이에 약 0.06초가 소요된다.

### 5.2 채택하지 않은 대안

| 대안 | 기각 사유 |
|---|---|
| A* 탐색 | 레퍼런스 문헌의 방법이나, 가정 3의 주기 제약으로 탐색공간이 이미 9개로 축소됐다. 탐색 알고리즘이 불필요하다 |
| 전수 탐색 | 레퍼런스 문헌이 impractical로 기각한 baseline이다 |
| Gurobi | 9개 조합 규모에 과잉이며, 상용 라이선스가 재현성을 저해한다 |
| Charnes-Cooper 변환 | 4.2절의 정정으로 불필요해졌다 |

### 5.3 shadow price 획득 시 주의

CBC는 정수변수가 남아 있으면 듀얼을 반환하지 않는다. **검사 주기 선택을 고정한 뒤 순수 LP로 재풀이해야 shadow price를 얻을 수 있다.**

### 5.4 파라미터 불확실성의 처리

설비·원가 계수의 절대값은 전부 비공개다. 따라서 본 연구의 입력은 데이터셋이 아니라 **파라미터 공간**이며, 공개 문헌으로 확보 가능한 범위를 삼각분포로 두고 2,000회 몬테카를로로 결론의 분포를 산출한다.

여기서 다루는 몬테카를로는 **파라미터 불확실성**에 대한 것이다. 불량 발생 사건의 몬테카를로는 수행하지 않는다 — 조기 폐기가 닫힌형을 가지므로 중복 계산이다.

|---|---|
| 최적 층수 | **12단** — 내부 최적점 존재, 단봉성 확인 |
| 단일 풀 shadow price | **0.20840** |
| 직접 계산한 시간당 이익 | **0.20840** |

### 7.2 설비 증설 우선순위는 품질 목표가 정한다

병목 전환점, 즉 본더와 테스터의 병목이 뒤바뀌는 캐파 비율 H_t/H_b를 DPPM 상한별로 산출했다.

| DPPM 상한 | 전환 H_t/H_b |
|---|---|
| 200 ppm | **1.1398** |
| 250 ppm | 0.8693 |
| 300 ppm | 0.7737 |
| 400 ppm | 0.5928 |
| **425 ppm 이상** | **0.5837 (평탄)** |

**곡선은 425 ppm에서 꺾이며 두 체제로 갈린다.**

> 품질 목표가 425 ppm보다 느슨하면 설비 증설 우선순위는 품질과 무관하다. 그보다 조이면 품질 목표가 우선순위를 결정하며, **200 ppm에서는 테스터 캐파가 본더를 초과해야 한다.**

품질을 조이면 검사 부하가 증가해 테스터가 먼저 소진되기 때문이다. **캐파 제약과 품질 제약을 같은 모델에 넣지 않으면 이 문장이 도출되지 않는다.** 선행 계보는 캐파가 없고, 캐파 문헌은 품질이 없다.

### 7.3 16단은 두 가지 원인으로 등장한다

층당 접합 수율 x를 0.9425~0.9900 구간에서 스윕한 결과, 16단 비중은 **단조가 아니다.**

| x 구간 | 16단 비중 | 구속 제약 |
|---|---|---|
| ≤ 0.9500 | 15~44% | C2 구속 — **수요가 강제** |
| 0.9525 ~ 0.9625 | **0%** | C2 비구속 — 경제성으로는 이기지 못함 |
| 0.9650 ~ 0.9800 | 3~80% | 전환 구간 — 구속 조합이 계속 변화 |
| ≥ 0.9825 | **100%** | C1-a만 구속 — **경제성이 선택** |

**같은 "16단 등장"이라도 양 끝의 원인이 정반대다.** 저수율 구간에서는 총 용량 목표를 맞추기 위해 수율이 나빠도 높이 쌓을 수밖에 없고, 고수율 구간에서는 수요 제약이 풀리고 설비 경제성만으로 16단이 선택된다.

이 결과는 **결과 해석 지침이 착수 시점에 사전 고정돼 있었기에** 사후 각색 없이 확인된 것이다. 지침은 "층수 상승이 고객 용량 요구가 강제한 것인지 설비 경제성 때문인지를 구분해 보고한다"였다.

### 7.4 검사 빈도는 검사 정확도를 대체할 수 없다

최종 검사 검출률 β_f별로 달성 가능한 출하 DPPM 하한(모든 적격 검사를 사용했을 때)을 산출했다.

| β_f | 달성 가능 하한 |
|---|---|
| 0.00 (최종 검사 없음) | **1,908.9 ppm** |
| 0.95 | **95.6 ppm** |

**최종 검사가 없으면 매 층 검사(k=1)를 하더라도 1,000 ppm 아래로 내려갈 수 없다.** 한 번 놓친 불량은 이후 검사에서도 같은 확률로 놓치므로, 횟수를 늘려도 하한이 존재한다.

MILP 이분탐색으로 구한 실행 가능 하한과 닫힌형 계산이 소수점까지 일치했다. **두 독립 경로로 확인된 구조적 결과이며, 파라미터를 맞춰 끼워 만든 값이 아니다.**

| 시간당 이익 J | 0.1527 | 0.0757 ~ 0.2888 |
| **병목 = 테스터 확률** | **71.9%** | — |

**층수 비중의 신뢰구간이 0~100%에 걸친다.** 즉 "최적 층수는 12단이다"라고 단정할 수 없다. 반면 **병목은 약 72% 확률로 테스터**다. 이 비대칭 자체가 결과다.

파라미터와 결과의 상관계수는 다음과 같다.

| 파라미터 | →16단 비중 | →시간당 이익 | →테스터 병목 |
|---|---|---|---|
| **x (층당 수율)** | **+0.476** | +0.326 | −0.030 |
| c_fix_b | +0.136 | −0.057 | +0.028 |
| a (고정시간 배수) | +0.132 | −0.196 | −0.139 |
| **θ (검사시간 배수)** | −0.124 | −0.266 | **+0.417** |
| β | −0.106 | +0.005 | −0.212 |
| β_f | −0.085 | +0.080 | −0.187 |
| r | −0.073 | +0.741 | −0.011 |
| c_test | −0.062 | +0.000 | +0.018 |
| c_base | +0.031 | −0.044 | −0.028 |
| ρ (캐파 비율) | +0.024 | −0.155 | −0.151 |

**결론 문장 두 개.**

> **층수 구성**을 정하려면 층당 접합 수율 x를 가장 정확히 측정해야 한다(+0.476). 원가 항목(c_base, c_test)은 50% 틀려도 결론이 바뀌지 않는다(|r| < 0.07).
>
> **어느 설비를 증설할지**를 정하려면 검사시간 배수 θ = t_test/t_stack을 가장 정확히 측정해야 한다(+0.417). 캐파 비율 ρ 자체(−0.151)보다 두 배 이상 중요하다.

**해석 주의.** r의 이익 상관 +0.741은 정보가치가 없다. 매출 스케일 파라미터이므로 이익에 비례하는 것이 당연하며, 층수 구성 상관은 −0.073으로 사실상 0이다. **의사결정을 바꾸지 않는 상관은 정보가치에서 제외해야 한다.**

**β_f의 낮은 상관(−0.085)도 결론의 일부다.** 7.4절과 종합하면 다음과 같다.

> **최종 검사는 존재 여부가 결정적이고, 검출률의 정밀도는 결론을 바꾸지 않는다.**

존재 여부의 근거는 역산 표(β_f = 0이면 어떤 k로도 1,000 ppm 미달)이고, 정밀도 무관의 근거는 몬테카를로(β_f ∈ [0.87, 0.99]에서 상관 −0.085)다. 두 근거의 출처가 다르므로 혼동해서는 안 된다.

### 7.6 병목이 검사 전략을 뒤집는다

제약을 하나씩만 활성화해 귀속을 분해한 결과, 단독 제약 케이스에서 최적 검사 주기가 정반대로 갈린다.

| 활성 제약 | 최적 k | 병목 |
|---|---|---|
| C1-a 단독 (본더만) | **k = 1 (100%)** | 본더 |
| C1-b 단독 (테스터만) | **k = 4 (97%)** | 테스터 |

> **본더가 병목이면 검사를 최대로, 테스터가 병목이면 최소로 한다.**

본더가 병목이면 테스터 시간이 사실상 공짜이므로, 자주 검사해 불량을 조기 폐기하고 본더 시간을 절약하는 것이 순이득이다. 테스터가 병목이면 검사 자체가 병목 자원을 소모하므로 최소화한다.

**이는 가정 2(조기 폐기)가 작동한다는 직접 증거이며, 극단값에서 재현된 결과다.**

### 7.7 믹스의 발생 원인 — 귀속 분해

제약별 leave-one-out 및 only-one 분해 결과는 다음과 같다.

| 활성 제약 | 층수 배분 | 종수 |
|---|---|---|
| C3(웨이퍼)만 | 12단 100% | 1종 |
| C4 단독 | 12단 100% | 1종 |
| C2 단독 | 12단 100% | 1종 |
| C1-a + C1-b | 12단 58% / 16단 42% | 2종 |
| C1-a + C1-b + C4 | 8단 48% / 12단 20% / 16단 32% | 3종 |

> **믹스의 종수는 동시에 구속되는 제약의 개수를 넘지 못한다.** 믹스의 뼈대는 본더·테스터 두 캐파 제약의 동시 구속이며, **C4가 제약하는 것은 검사 주기 k**다.

선형계획에서 기저 최적해의 비영 변수 개수는 구속 제약 개수 이하이며, 위 표에서 등호가 성립한 것은 축퇴가 없었기 때문이다.

이 결과는 3.3절의 성질("DPPM은 층수가 아니라 검사 주기가 결정한다")과 대칭을 이룬다. 그 역방향인 "C4는 층수가 아니라 검사 주기를 제약한다"가 성립해야 했다.

### 7.8 층수 다양화와 검사 주기 다양화는 대체재다

가정 3의 단일 주기 제약을 해제해 12단이 k = 2와 k = 4를 동시에 가질 수 있게 하면, **16단이 사라지고 12단 k = 4가 그 자리를 대신한다**(16단 32% → 0%, 12단 k=4 0% → 29%).

> **층수를 다양화하는 것과 검사 주기를 다양화하는 것은 서로 대체재다.**

12단이 두 주기를 가질 수 있으면 16단이 필요 없고, 못 가지면 16단이 그 자리를 떠맡는다. **이는 층수와 검사를 동시에 결정변수로 놓았기 때문에만 관측되며, 선행연구에 없다.**

제약 해제의 기회비용은 총이익 **+0.11%**(품질 제약 적용) ~ **+1.43%**(미적용)다. 즉 **라인 운영 현실을 반영한 대가가 1.5% 이내**로 정량화된다.

### 7.9 매출 선형성 가정의 강건성

층수 프리미엄, 즉 16단의 GB당 단가가 8단보다 높을 가능성을 시나리오로 시험했다. **프리미엄이 15%까지 상승해도 최적 믹스가 변하지 않으며, 25%에서 처음 뒤집힌다.** 관측 근거가 5~15% 범위이므로, 이 반증 가능성은 한계가 아니라 **강건성의 근거**로 보고한다.

### 8.1 미확보 파라미터

| 항목 | 상태 |
|---|---|
| a, θ, r, c_base, c_fix_b | 공개 자료에 절대값 없음. 삼각분포 시나리오로 처리 |

| β_f | 존재는 문헌으로 확증, 수치는 역산값 |

θ와 a는 공개 문헌 조사를 2회 시도했으나 절대값을 확보하지 못했다. 테스터 UPH 공식과 병렬 site 수는 확보했으나 소크·테스트·인덱스 시간이 없어 역산이 성립하지 않는다. 다만 부수적으로 **t_stack의 내부 구성이 분해**되어, 정밀 정렬 2~3초와 TCB 본딩 사이클 3~8초의 합이 기준값 5.4초를 독립 출처로 뒷받침했다.

### 8.2 업계 DPPM과의 비교를 수행하지 않은 이유

본 모델의 출하 DPPM은 **접합 불량 미검출만을 계상**한다. 업계 DPPM은 다이 자체 불량, 초기 신뢰성 고장, 전기적 파라미터 이탈을 모두 포함하므로 본 모델 값은 그 부분집합이다. 또한 공개 자료에서 HBM 출하 DPPM 목표치를 확보하지 못해 분모 단위(스택 대 die)를 확인할 수 없었다.

**따라서 업계 값과의 직접 비교는 수행하지 않았다.** 근거가 확보되지 않은 비교를 제시하지 않는 것이 정직한 처리다.

> **"최적 층수는 12단이다."**

### 8.5 방법론적 기록

본 연구는 진행 중 세 건의 오류를 발견하고 정정했다. 결과 문서에는 정정된 형태만 남지만, 방법론적 시사가 있으므로 기록한다.

1. **설계 단계에서 타당해 보인 목적함수가 구현 후 무너졌다.** 분수형의 규모 무관성은 지면상으로 드러나지 않았고, shadow price가 전부 0으로 산출되고서야 확인됐다. 다만 "shadow price를 확인한다"를 검증 항목으로 사전 설계해둔 덕에 조기에 포착됐다.
2. **두 단계의 결론이 양립 불가였으나 각 단계 안에서는 정합적이라 넘어갔다.** 3.3절의 성질과 초기 믹스 귀속 서술이 서로 모순이었다. **단계 간 정합성 점검을 절차로 두어야 한다.**
3. **검증 없이 단정한 메커니즘 해석이 반증 테스트에서 정반대로 나왔다.** 8단 등장을 단일 주기 제약의 부산물로 해석했으나, 제약을 해제하자 8단이 오히려 증가했고 대신 16단이 사라졌다(7.8절). **메커니즘은 반증 테스트 전에 확정 서술로 기재하지 않는다.**

## 9. 결론

설비 처리량 제약 하에서 HBM 층수 구성과 층 단위 검사 주기를 동시에 결정하는 MILP 모델을 제시했다. 선행 계보가 원가만을 다루고 층수를 주어진 파라미터로 둔 것과 달리, 본더·테스터를 분리된 자원으로 모델링하고 층수를 결정변수로 승격했다.

**층수 최적점에 대한 일반 규칙은 제시할 수 없다.** 파라미터 값들의 상호작용에 따라 최적 구성이 달라지기 때문이며, 이는 레퍼런스 문헌이 도달한 결론과 동일하다. 그러나 본 연구는 **답이 갈리는 임계 조건들을 명시**할 수 있었다.

- 병목 전환점은 품질 목표의 함수이며, 425 ppm을 경계로 상수 구간과 급증 구간으로 나뉜다
- 16단의 등장 원인은 수율 구간에 따라 수요 강제와 경제성 선택으로 갈린다
- 중간 검사의 성격은 277 ppm을 경계로 품질 수단과 설비시간 절감 수단으로 갈린다
- 최종 검사는 존재 여부가 결정적이고 검출률의 정밀도는 무관하다

또한 정보가치 분석을 통해 **어떤 파라미터를 정확히 측정해야 하고 어떤 것은 추정으로 충분한지**를 정량으로 구분했다. 데이터가 없다는 제약을 "무엇을 측정해야 하는가"라는 결론으로 전환한 것이 방법론적 기여다.

**후속 과제.** 중간 검사와 최종 검사 사이의 투자 배분(β, β_f의 2차원 최적화)은 두 파라미터가 모두 미확보인 현 상태에서는 근거 없는 축을 만드는 결과가 되므로 수행하지 않았다. 실측이 확보되면 다룰 수 있다. 이산사건 시뮬레이션(DES)을 통한 라인 동역학 반영 역시 범위 밖으로 두었다.

## 부록 A — 조기 폐기 기대값의 유도

L층 스택에 대해 층 i에서 첫 불량이 발생할 확률은 x^(i−1)(1 − x)다. 검사는 k, 2k, …, L 지점에서 수행되며, 층 i의 불량은 i 이상의 검사 지점에서 각각 확률 β로 검출된다.

층 i에서 불량이 발생한 경우, 검출 가능한 최초 지점의 인덱스를 ⌈i/k⌉라 하면 남은 검사 기회는 m = L/k − ⌈i/k⌉ + 1회다. j번째 기회에서 검출될 확률은 (1 − β)^(j−1)·β이며, 그때까지 적층된 층수는 (⌈i/k⌉ + j − 1)·k다. m회 모두 미검출될 확률은 (1 − β)^m이고, 이 경우 L층까지 적층되어 escape가 된다.

따라서 다음이 성립한다.

> E[layer] = x^L·L + Σ_i x^(i−1)(1−x) [ Σ_j (1−β)^(j−1) β · (⌈i/k⌉+j−1)k + (1−β)^m · L ]

E[test]는 동일한 분기에서 적층 층수를 k로 나눈 값으로 계산된다.

**특수 경우.** k = 1, β = 1이면 모든 불량이 발생 즉시 검출되므로

> E[layer] = Σ_{i=1}^{L} x^(i−1)(1−x)·i + x^L·L = (1 − x^L)/(1 − x)

가 된다. 이는 첫 실패까지의 시행 횟수를 L에서 절단한 기대값과 같다. x = 0.965에서 L = 8, 12, 16에 대해 각각 7.09, 9.94, 12.42다.

**최종 검사의 반영.** 가정 4에 따라 escape는 최종 검사에서 확률 β_f로 추가 검출되므로, 출하 기준 미검출 비율은 p_escape·(1 − β_f)가 된다. 최종 검사는 모든 완결 스택이 상시로 거치므로 (L, k)와 무관한 고정 성분이며, 목적함수에 상수를 더할 뿐 최적해를 바꾸지 않는다. 따라서 시간·원가에는 계상하지 않고 escape에만 곱한다.
