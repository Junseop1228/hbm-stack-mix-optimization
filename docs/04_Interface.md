# Block Interface

**HBM Stack Mix Optimization** | v1.4 | 2026.08.12
**전제**: 검사 효과 모델 = ① 조기 폐기 (01_Spec.md 3.6절)

> 이 문서의 목적은 하나다. **두 사람이 같은 (L, k)에 서로 다른 가정을 넣어 조용히 틀리는 것을 막는다.**
> 구버전(KGD)은 블록이 단방향이라 이 문서가 필요 없었다. 현 구조는 두 블록이 병렬이고 공통 입력을 공유하므로 필수다.

## 1. 블록 구조

두 모듈은 **서로에게 데이터를 주지 않는다.** 각각 공통 입력 (L, k)를 받아 독립적으로 계산하고, 결과를 결합층에 올린다.

**구조도**

    [공유 파라미터 06_Parameters.md]
                |
        +-------+-------+
        |               |
    Block Y          Block T
    수율·검사        설비·원가
        |               |
    확률·기대횟수    시간·비용 계수
        |               |
        +-------+-------+
                |
            [결합층]
          E[T], E[C], MILP
                |
         [시나리오·해석]

**중요한 귀결**: 한쪽 모듈이 미완성이어도 다른 쪽은 독립적으로 완주할 수 있다. **한 모듈의 미확정이 다른 모듈로 전파되지 않는다.** 실제로 Block T 의 계수가 전부 미확보인 상태에서 Block Y 와 결합층·시나리오까지 완주했다.

**단, 예외 1건** — Block T 의 T_fix 분해(6절)는 Block Y 의 조기 폐기 모델이 요구해서 생긴 항목이다. 일방향 의존이므로 명시해둔다.

## 2. ★ 인덱스·기호 규약 (조용한 오류의 최대 발원지)

**여기서 어긋나면 두 블록의 숫자가 전부 틀린다. 코드 작성 전 반드시 합의 확인.**

| 기호 | 정의 | 주의 |
|---|---|---|
| **L** | **core DRAM die 수** | base die 제외. 8-Hi면 L = 8이고 총 층수는 9다 |
| 총 층수 | L + 1 | 표기에 쓰지 않는다. 혼동 방지를 위해 코드에는 L만 쓴다 |
| bond step 수 | L | core die 1장 부착 = 1 step. base die는 캐리어에 먼저 놓임 |
| **k** | 검사 주기 | k층마다 1회. k ∈ {1, 2, 4} |
| 검사 지점 | k, 2k, …, L | L이 k의 배수가 아니면 마지막 지점은 L로 절삭 |
| 총 검사 횟수 | ⌊L/k⌋ | **불량 없는 스택 기준**. 실제 기대값은 E_test |
| **x** | **층당 접합 수율** | bond step 1회의 성공 확률. 스택 수율 아님 |
| **β** | 검사 검출률 | 검사 1회가 기존 불량을 잡아낼 확률 |
| 층 번호 i | 1 … L | 아래에서 위로. base die 바로 위가 i = 1 |

**L = 16, k = 4 예시로 상호 검산할 것**: 검사 지점 = 4, 8, 12, 16 → 4회. 이 값이 서로 다르게 나오면 규약 해석이 갈린 것이다.

## 4. Block Y (수율·검사) → 결합층

**산출물**: (L, k) 9개 조합에 대한 표 1장. 투입 스택 1개 기준.

| 컬럼 | 기호 | 단위 | 정의 | 범위 검증 |
|---|---|---|---|---|
| `L` | L | layer | core die 수 | {8, 12, 16} |
| `k` | k | layer | 검사 주기 | {1, 2, 4} |
| `e_layer` | E[layer] | layer | 폐기 시점까지 실제로 쌓은 층수의 기대값 | 1 ≤ e_layer ≤ L |
| `e_test` | E[test] | 회 | 폐기 시점까지 수행한 검사 횟수의 기대값 | 0 ≤ e_test ≤ ⌊L/k⌋ |
| `p_good` | x^L | — | 무결점 스택 비율 | k와 무관 |
| `p_escape` | — | — | 불량인데 미검출로 끝까지 간 비율 | β=1이면 0 |
| `p_complete` | — | — | 폐기되지 않고 최종 단계까지 간 비율 | p_good + p_escape |
| `e_die` | — | 개 | 소모 die 수 기대값 | 1 + e_layer (base die 포함) |
| `dppm` | — | ppm | 출하 불량률 = p_escape / p_complete × 1e6 | C4 대상 |

**계산 근거**: 01_Spec.md 3.6.1

**★ escape의 매출 처리 가정 (명시)**

> escape(불량인데 미검출로 출하된 스택)는 **출하되어 DPPM에 계상되나, 반품·교체 처리되어 매출로 계상하지 않는다.**

따라서 목적함수의 매출 계수는 **p_good**, DPPM의 분모는 **p_complete**다. 두 기준이 다른 것은 오류가 아니라 위 가정의 귀결이다. 품질 원가(COPQ)의 표준 처리와 일치한다.

**대안을 채택하지 않은 이유**: 매출을 p_complete로 잡으면 불량품 매출을 인정하게 되고, escape에 대한 억제 장치가 C4 하나만 남아 검사의 가치가 과소평가된다.

**정의상 반드시 성립해야 하는 항등식 3개** (자체 검증용)

1. p_good + p_escape + p_discard = 1
2. p_good = x^L (k, β와 무관하다. 이게 깨지면 모델이 틀린 것)
3. k가 작아질수록 e_layer는 감소하고 e_test는 증가한다 (단조성)

**3번이 이 프로젝트의 상충 구조 그 자체다.** 단조성이 깨지면 코드 오류다.

## 5. Block T (설비·원가) → 결합층

**산출물**: 시간·비용 계수. (L, k)별 표가 아니라 **스칼라 계수**다. 조합별 값은 결합층에서 만든다.

| 계수 | 기호 | 단위 | 정의 |
|---|---|---|---|
| `t_fix_a` | T_fix(a) | 초/스택 | 적층 **이전** 고정 시간 (로딩·정렬·캐리어 준비) |
| `t_fix_b` | T_fix(b) | 초/스택 | 적층 **이후** 고정 시간 (mass reflow·몰딩·언로딩) |
| `t_stack` | t_stack | 초/층 | 층 1장 배치 + 가고정 |
| `t_test` | t_test | 초/회 | 검사 인서션 1회 |
| `cap_bond` | H_b | 초/기간 | 본더 가용 시간 |
| `cap_test` | H_t | 초/기간 | 테스터 가용 시간 (**분리 확정**, 7.1) |
| `c_die` | — | 정규화 | core die 1장 = 1.0 기준 |
| `c_base` | — | 정규화 | base die 원가비 |
| `c_test` | — | 정규화 | 검사 1회 비용 |

**★ T_fix 분해가 왜 필요한가 (조기 폐기의 직접적 귀결)**

중도 폐기된 스택은 mass reflow와 몰딩을 거치지 않는다. T_fix를 한 덩어리로 두면 **폐기된 스택도 몰딩 시간을 쓴 것으로 계산되어 조기 폐기의 이득이 사라진다.** k의 최적점이 사라지고 모델이 층수 결정만 남는다.

따라서 분해가 필수다. 절대값은 미확보이므로 **비율 ψ = T_fix(a) / T_fix**로 두고 시나리오 변수로 흔든다. 기본값 제안 0.2 (대부분의 고정 시간이 몰딩·리플로우 쪽이라는 3.3.1의 구조적 근거 반영).

## 6. 결합 함수 — 정의 위치와 형태

**결합 함수는 어느 모듈에도 속하지 않는다. 결합층 파일 한 곳에 둔다.** 각 모듈에서 따로 결합 계산을 하면 두 벌이 생기고 반드시 어긋난다.

**투입 스택 1개당 기대 설비 점유시간**

> E[T_bond](L,k) = t_fix_a + t_stack × e_layer
> **t_fix_b는 본더 캐파 식에서 제외한다** — 리플로우·몰딩은 저가·고처리량 배치 설비라 제약 자원이 아니다 (06_Parameters 3.3). 원가식에는 남는다.
> E[T_test](L,k) = t_test × e_test
> E[T](L,k) = E[T_bond] + E[T_test]

**투입 스택 1개당 기대 원가**

> E[C](L,k) = c_base + c_die × e_layer + c_test × e_test + p_complete × c_fix_b

**목적함수** (v1.4 정정, 2026.08.12)

> maximize Σ_(L,k) [ (p × c × L × p_good − E[C](L,k)) × q_(L,k) ]
> **총이익 최대화. 캐파는 제약으로 남긴다.**

**분수형(시간당 이익)을 목적함수로 두지 않는다.** 규모 무관성 때문에 캐파 제약이 구속되지 않고 병목이 사라진다. 상세는 01_Spec 3.7.1.

**시간당 이익 J는 결과 지표로 계산해 보고한다.**

> J = Σ 이익·q / Σ E[T]·q

그리고 **캐파 제약의 shadow price가 곧 그 설비 1초의 한계이익**이다. 병목 = 듀얼이 큰 쪽.

**구현 주의**: CBC는 정수변수가 남아 있으면 듀얼을 반환하지 않는다. **k 선택을 고정한 뒤 순수 LP로 재풀이해야 shadow price가 나온다.** `src/milp.py` 참조.

## 7. ★ 결정 필요 2건 — 코드 착수 전

### 7.1 ✅ 확정 — 설비 풀 분리 (2026.08.11)

**본더 캐파와 테스터 캐파를 별도 제약으로 둔다.** C1이 두 줄로 분리된다.

> C1-a (본더): Σ_L q_L × E[T_bond](L, k_L) ≤ H_b
> C1-b (테스터): Σ_L q_L × E[T_test](L, k_L) ≤ H_t

**병목 판정 = 어느 쪽 제약의 shadow price가 큰가.** 시나리오 C에서 H_t / H_b 비율을 흔들어 병목이 전환되는 임계점을 도출한다. 이것이 결과물의 대표 그림 1장이 된다.

#### (판단 근거 기록)

| 안 | 내용 | 평가 |
|---|---|---|
| **단일 풀** | 본딩과 검사가 같은 시간 예산을 나눠 씀 | 단순. 상충 구조가 한 제약 안에서 직접 보임 |
| **분리 풀** | 본더 캐파와 테스터 캐파를 별도 제약으로 | **✅ 채택** |

**분리를 권장하는 이유 2가지**

1. **공정 현실이다.** 본딩 장비와 테스트 장비는 다른 설비다. 검사를 늘리면 테스터 시간을 쓰고 본더 시간을 아낀다 — 서로 다른 풀 사이의 대체다.
2. **JD 키워드에 정확히 꽂힌다.** 삼성 TSP 생산관리 JD 원문의 "설비 자원 운용 계획 수립 및 **Bottleneck 운영 최적화**"가 바로 이것이다. 단일 풀이면 병목 판정이라는 개념이 성립하지 않는다.

**비용**: 제약식 한 줄과 파라미터 하나(테스터 캐파 비율) 추가뿐이다. MILP 구조는 그대로다.

**기본 시나리오**: 테스터 여유가 충분한 상태에서 시작해, 시나리오 C에서 두 캐파 비율을 흔들어 **병목이 본더에서 테스터로 넘어가는 임계점**을 찾는다. 이게 결과물의 핵심 그림 하나가 된다.

### 7.2 ψ (T_fix의 적층 전/후 분해 비율)

Block T 파라미터. 절대값 미확보이므로 무차원 비율로 두고 0.1 ~ 0.4 범위 민감도. **10절 2번과 통합.**

## 9. 통합 검증 기준 (3주차 통합 시점에 실행)

**통합 전에 각 모듈에서 통과시킨다. 통합 시점에 발견하면 늦다.**

| # | 검증 | 기대 결과 |
|---|---|---|
| 1 | **범위** | 1 ≤ e_layer ≤ L, 0 ≤ e_test ≤ ⌊L/k⌋, 모든 확률 ∈ [0,1] |
| 2 | **항등식** | p_good + p_escape + p_discard = 1 (오차 1e-9 이내) |
| 3 | **k 불변성** | x, L 고정 시 k를 바꿔도 p_good이 변하지 않는다 |
| 4 | **단조성** | k 증가 → e_layer 증가, e_test 감소 |
| 5 | **극단값 A** | x → 1: e_layer → L, p_good → 1, dppm → 0 |
| 6 | **극단값 B** | β → 0: 검사가 무의미해져 e_layer → L, dppm 최대 |
| 7 | **극단값 C** | φ → 0: 최소 층수가 유리 (고정성분 분산 이득 소멸) |
| 8 | **문헌 재현** | 캐파 제약(C1) 해제 시 선행연구 결론(층수 최적점 존재)이 재현되는가 |
| 9 | **단위 정합** | E[T] 총합 × 생산량이 가용 설비시간과 같은 자릿수인가 |

**8번이 가장 중요하다.** 캐파 제약을 빼면 우리 모델은 선행연구와 같은 문제가 되어야 한다. 여기서 다른 답이 나오면 우리 모델이 틀렸거나, 차별점 ①의 서술이 과장된 것이다.
